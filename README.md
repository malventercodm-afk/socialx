# SocialX

SocialX is a React Native / Expo starter based on the SocialX concept.

## Included
- SocialX branding and dark UI
- Home feed
- Stories/composer
- Friends & followers
- Reels
- Communities
- Marketplace
- Profile
- Messenger
- Bottom navigation

## Run it

1. Install Node.js.
2. In this folder run:
   `npm install`
3. Run:
   `npx expo start`
4. Scan the QR code with Expo Go, or press `a` for Android / `i` for iOS.

## Important

This is a functional UI starter, not a production social network yet.

For production you still need:
- User authentication
- Database
- User profiles
- Posts and image/video uploads
- Real-time chat
- Push notifications
- Search/indexing
- Marketplace listings and payments
- Moderation/reporting
- Admin dashboard
- Privacy/security rules
- Cloud storage/CDN
- Production deployment

A practical backend can be Supabase or Firebase. The UI is intentionally separated into screens so the backend can be connected later.
